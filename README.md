## 🌟 Highlights & Overview

**Ooze Cafe** is a fast, responsive, and visually appealing web application built for a modern cafe and dine-in / delivery restaurant. Featuring over **156+ curated menu items across 15 mouth-watering categories**, seamless **one-click WhatsApp ordering**, **smart search & filters**, and an **integrated admin management suite**.

```
  🍽️ 156+ Handcrafted Menu Items      📱 1-Click WhatsApp Ordering
  🍕 15 Diverse Cuisine Categories      ⚡ Sub-Second Vite Performance
  💳 Multi-Currency Support (₹, $, €)    🔒 Protected Admin Dashboard
  📱 100% Mobile & PWA Responsive        🚀 Zero-Friction User Experience
```

## ✨ Key Features

<div align="center">

| Feature | Description | Highlight |
| :--- | :--- | :---: |
| ⚡ **Lightning Fast Experience** | Zero lag navigation powered by Vite 7 and optimized asset pipelines | `React 19` |
| 📱 **Mobile-First & PWA Ready** | Fluid swipe gestures, sticky navigation, and installable web application | `PWA` |
| 🔍 **Live Search & Quick Filters** | Instant dish search by keyword, category, spice level, or vegetarian preference | `Instant` |
| 📲 **1-Click WhatsApp Ordering** | Generates pre-formatted WhatsApp cart messages sent straight to the cafe line | `WhatsApp API` |
| 🎛️ **Full Admin Suite** | Real-time analytics, inventory toggle, pricing edits, and category management | `Admin Panel` |
| 🌐 **Multi-Currency Ready** | Flexible currency switching (₹ INR, $ USD, € EUR, £ GBP) | `Global` |
| 🛡️ **Zero Downtime Routing** | Clean client-side routing with deep-link support on GitHub Pages and static hosts | `SPA` |

## 🚀 Quick Start & Installation

### 1. Clone the Repository
```bash
git clone https://github.com/khadeeja-zakkiya/ooze_cafe.git
cd ooze_cafe/frontend
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Start Local Development Server
```bash
npm run dev
```
> The application will start at `http://localhost:5173` (or `http://localhost:5178`)

### 4. Build for Production
```bash
npm run build
npm run preview
```

### 5. Deploy to GitHub Pages
```bash
npm run deploy
```
